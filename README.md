\# Mi Proyecto Python



\## 📌 Descripción

Este proyecto es una aplicación en Python que se conecta a la API de GitHub usando la librería requests.



\## 🐍 Versión de Python utilizada

Python 3.12.0



\## 📦 Dependencias

\- requests



\## ⚙️ Instalación



1\. Clonar el repositorio:

git clone https://github.com/tuusuario/mi\_proyecto\_python.git



2\. Crear entorno virtual:

python -m venv venv



3\. Activar entorno virtual:

Windows:

venv\\Scripts\\activate



4\. Instalar dependencias:

pip install -r requirements.txt



\## ▶️ Ejecución



python main.py
